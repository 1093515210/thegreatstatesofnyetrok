# 第一章：总则（第1条 - 第9条）
第1条【立法宗旨】保障私法自治与契约自由，确立商事主体平等地位，规范公司设立与运营，激发市场活力。

第2条【适用范围】九州邦联主权管辖境内及数字自由港内之一切民商事契约、公司设立、股权治理及商事交易行为。

第3条【契约自由原则】民事主体在法律规定范围内享有自愿订立契约之权利，任何单位和个人不得非法干预。

第4条【意思自治优先】法律关于民商事规范之规定，除涉及公共安全、强制性人权及反垄断底线外，均优先尊重当事人之自由约定。

第5条【诚实信用原则】民事主体从事商事活动应当遵循诚实信用，恪守承诺，维持公平交易秩序。

第6条【商事主体平等】各类所有制、资本来源及组织形式之企业在法律适用、市场准入与政策支持上一律平等。

第7条【契约严守原则】依法成立之契约对当事人具有法律约束力，非经法定程序或契约约定，不得擅自变更或解除。

第8条【公序良俗底线】契约内容不得违背邦联宪章之基本人权原则、社会公序良俗及强行法规范。

第9条【商事习惯适用】商事交易中无明文规定时，得依法适用合法、合规之地方商事习惯与行业通行规则。

# 第二章：合同的订立与效力（第10条 - 第24条）
第10条【要约与承诺机制】合同通过要约与承诺方式达成，当事人意思表示一致即告成立。

第11条【电子合同法律效力】采用电子数据交换、电子邮件、区块链智能合约等形式订立之电子契约，与书面契约具有同等法律效力。

第12条【智能合约自执行】承认经各方授权部署之去中心化智能合约之自动履约效力，非经法定事由或协商一致不得单方阻断。

第13条【格式条款规制】提供格式条款订立合同之一方，须以合理方式提请对方注意免除或限制其责任之条款。

第14条【无效合同情形】违反法律强制性规定、恶意串通损害国家或第三人利益、违背公序良俗之契约自始无效。

第15条【可撤销合同】因重大误解、显失公平、欺诈或胁迫订立之合同，受损害方有权请求法院或仲裁机构予以撤销。

第16条【合同无效之处理】合同无效或被撤销后，因该合同取得之财产应当予以返还；有过错之一方应当赔偿对方损失。

第17条【合同解释规则】合同条款存有歧义时，应结合上下文、交易习惯及诚实信用原则进行合理文义与目的解释。

第18条【格式条款不利解释】对格式条款有两种以上解释的，应当作出不利于提供格式条款一方的解释。

第19条【合同保全（代位权）】债务人怠于行使其对次债务人之到期债权影响债权人实现债权的，债权人享有代位诉讼之权利。

第20条【合同保全（撤销权）】债务人无偿或以不合理低价处分财产影响债权实现时，债权人有权请求法院撤销该行为。

第21条【合同之变更与解除】经当事人协商一致，可以变更或解除合同；约定或法定解除条件成就时，权利人得行使解除权。

第22条【不可抗力免责】因不能预见、不能避免且不能克服之客观情况（不可抗力）导致合同无法履行的，根据影响程度部分或全部免除责任。

第23条【情势变更原则】合同成立后客观环境发生当事人无法预见的重大变化，继续履行明显不公平的，允许重协商或请求司法调整。

第24条【合同之违约责任】当事人不履行合同义务或者履行合同义务不符合约定的，应当承担继续履行、采取补救措施或者赔偿损失等违约责任。

# 第三章：公司设立与极简准入（第25条 - 第38条）
第25条【公司形式自由】公民及法人依法享有设立有限责任公司、股份有限公司、合伙企业及个体商号之自由。

第26条【认缴资本登记制】公司设立实行极简之认缴资本登记制，取消最低注册资本限额与验资前置审批。

第27条【无纸化电子注册】推行全流程线上、无纸化、标准化之公司智能备案与数字营业执照申领制度。

第28条【经营范围自主】除涉及军事武器、核材料等特许管控领域外，公司经营范围依法实行自主申报、法无禁止即可为。

第29条【公司章程自治】公司章程为规范内部治理之最高契约，股东得在法律底线内自由约定股权比例、表决权与分红规则。

第30条【一人公司与法人格】允许设立一人有限责任公司，股东依法享有有限责任保护，但滥用独立地位逃避债务者须承担连带责任。

第31条【分支机构与办事处】公司设立分公司、办事处或海外节点实行便捷备案制，无需重复繁琐行政审批。

第32条【无形资产与数字资产出资】允许以知识产权、开源代码、加密通证、数据资产及劳务等形式进行公司作价出资。

第33条【发起人责任界定】公司设立过程中因发起人过失导致债权人损失的，由相关发起人承担连带民事责任。

第34条【公司章程备案即生效】章程经全体股东签署或通过电子认证后即告生效，行政机关仅做形式备案，不得作实质内容审查。

第35条【企业名称自主选择】企业名称享有高度自主命名权，只要不与已注册企业重名且不违反公序良俗，行政机关不得驳回。

第36条【住所地灵活登记】允许使用虚拟办公地址、联合办公空间及数字节点作为公司法定注册地址。

第37条【禁止行政特许准入】除法律明确规定之特许行业外，任何部门不得对特定商业领域设置行政准入壁垒。

第38条【公司成立之法律节点】营业执照签发或电子备案完成之日，即为公司法人资格取得之日。

# 第四章：公司治理与股权结构（第39条 - 第56条）
第39条【股东会最高权力】股东会或股东大会为公司权力机关，决定公司重大战略、利润分配及合并分立。

第40条【董事会执行机构】公司设董事会负责经营决策，董事由股东会选举产生，对全体股东勤勉尽责。

第41条【经理层授权经营】董事会得聘任总经理负责日常日常运营，并在章程授权范围内独立行使经营管理权。

第42条【监事会或审计委员会】公司得自主选择设立监事会、独立审计委员会或引入第三方独立合规监督机制。

第43条【同股同权与同股异权】允许股份有限公司根据章程设置多重投票权（AB股结构），保障创始人技术路线控制权。

第44条【优先股与可转债创新】支持公司依法发行优先股、永续债、可转换债券等多样化资本工具。

第45条【股东知情权与查阅权】股东有权查阅公司财务账簿、会计凭证及股东会会议记录，防范内部人暗箱操作。

第46条【中小股东权益保护】设置累积投票权及中小股东表决机制，防止控股股东通过绝对多数侵害少数股东权益。

第47条【关联交易回避表决】董事或控股股东涉及与公司有利害关系之关联交易时，须强制回避表决。

第48条【董监高信义义务】董事、监事、高级管理人员对公司负有忠实与勤勉义务，严禁侵占公司商业机会。

第49条【股东代表诉讼机制】董事或高管侵害公司利益导致公司怠于起诉时，符合比例之中小股东有权提起代表诉讼。

第50条【股份自由转让原则】有限责任公司股东向外部转让股权，在同等条件下其他股东享有优先购买权，但章程另有约定除外。

第51条【股份有限公司股份流通】股份有限公司之股票与公开股权依法享有自由流转与证券化交易之权利。

第52条【股权代持之法律效力】承认真实出资人与名义代持人之间合法契约之效力，但不得对抗善意第三人。

第53条【利润分配自主权】公司年度利润在弥补亏损和提取任意公积金后，由股东会依法自主决定分配方案。

第54条【公司决议撤销之诉】股东会或董事会决议内容违反法律或章程的，股东有权自决议作出之日起向法院请求撤销。

第55条【董事勤勉责任豁免】董事基于商业判断做出之决策即便后期亏损，若程序合规且无故意懈怠，享有商业判断规则豁免。

第56条【分布式自治组织（DAO）治理衔接】承认采用区块链链上投票、智能合约治理之新型数字化组织（DAO）的商事契约主体地位。

# 第五章：并购、重组与资本运作（第57条 - 第67条）
第57条【并购自由与契约重组】公司之间可以通过吸收合并、新设合并、资产收购或股权置换等方式进行自由并购。

第58条【债权人保护程序】公司合并或分立必须书面通知债权人，债权人有权依法要求清偿债务或提供相应担保。

第59条【资产剥离与重组自主】公司有权依法自主剥离非核心资产、重组业务板块，任何行政机关不得强制捆绑。

第60条【敌意收购与反收购契约】上市公司章程中得依法设置“毒丸计划”、“金色伞”等符合契约自由之防卫机制。

第61条【股份回购合法化】公司在减少注册资本、员工股权激励或保护公司价值等法定情形下，有权自主回购本公司股份。

第62条【管理层收购（MBO）规范】允许管理层在信息充分披露、程序公正及防范利益输送前提下实施管理层收购。

第63条【跨境资本自由流动】自由港内企业享有无外汇管制障碍的跨境投资、利润汇回与资本重组权利。

第64条【跨国技术与知识产权并购】鼓励跨国技术资本并购，简化境外母公司与境内技术团队之股权架构调整审批。

第65条【重组过程信息披露】上市公司及公众公司在重大并购重组期间，须履行真实、准确、完整之信息披露义务。

第66条【内幕交易与操纵市场禁令】严厉打击利用未公开信息进行内幕交易、操纵市场及恶意欺诈之资本运作行为。

第67条【破产重整优先原则】陷入财务危机但具重整价值之企业，依法优先适用破产重整程序以恢复持续经营能力。

# 第六章：公司解散、清算与破产（第68条 - 第81条）
第68条【解散事由法定与约定】公司因营业期限届满、股东会决议解散、被依法吊销或破产等事由解散。

第69条【司法解散救济】公司经营管理发生严重困难（如长期僵局），继续存续会使股东利益受到重大损失，且通过其他途径不能解决的，持有表决权一定比例以上之股东可请求法院判决解散。

第70条【清算组组成与职责】公司解散后应当在法定期限内成立清算组，负责清理财产、编制资产负债表及处理未了结业务。

第71条【清算期间法人地位】公司清算期间存续，但不得开展与清算无关的新业务经营活动。

第72条【清偿顺序铁律】公司财产在支付清算费用和职工工资、社会保险费用、法定补偿金后，优先清偿税款与普通破产债权。

第73条【剩余财产按股分配】公司清偿全部债务后的剩余财产，按照股东出资比例或章程约定进行公平分配。

第74条【清算完结与注销登记】清算报告经股东会确认并报经登记机关备案后，公司法人资格正式消灭。

第75条【破产清算与重整启动】当企业资产不足以清偿全部债务或者明显缺乏清偿能力时，得依法申请破产重整、和解或清算。

第76条【破产管理人独立履职】破产程序中由法院依法指定中立、专业的破产管理人，全面接管债务人财产与印章。

第77条【破产重整优先于清算】法律鼓励通过债务重组、债转股或引入白衣骑士等方式实施重整，最大化保全企业资产与就业。

第78条【取回权与别除权保护】对破产企业中属于他人的财产享有取回权；对特定财产享有担保物权的债权人享有别除权。

第79条【撤销权追回资产】破产前一年内无偿转让财产、以明显不合理低价交易或对部分债权人个别清偿的行为，管理人有权请求法院撤销并追回。

第80条【破产终结与债务豁免】破产财产分配完毕后，管理人提请法院终结破产程序；自然人股东及有限责任公司在依法清算后免除未清偿之剩余债务（诚信破产保护）。

第81条【恶意逃债追究机制】对在解散或破产过程中隐匿财产、恶意转移资产或虚构债务逃废债之实控人与高管，追究无限连带赔偿与刑事欺诈责任。

# 第七章：商事争议解决与法律责任（第82条 - 第92条）
第82条【商事仲裁优先原则】鼓励商事主体在合同中约定仲裁条款，提倡通过独立、民营、国际化的商事仲裁机构解决契约纠纷。

第83条【诉讼管辖约定自由】合同当事人可以在不违反级别管辖前提下，协议选择被告住所地、合同履行地、原告住所地、标的物所在地等与争议有实际联系之法院管辖。

第84条【举证责任分配规则】民商事诉讼中实行“谁主张、谁举证”，但在数字契约及特殊侵权中依法适用举证责任倒置。

第85条【商事调解法定地位】经依法设立之商事调解机构达成的调解协议，具有民事合同约束力，当事人可共同向法院申请司法确认。

第86条【跨境商事裁决承认】九州邦联承认并执行境内外符合国际公约及对等原则之商事仲裁裁决与法院判决。

第87条【违反契约之民事惩罚】恶意违约、严重违背商业诚信给对方造成重大损失的，除赔偿实际损失外，得依法判处惩罚性赔偿。

第88条【行政干预民商事赔偿】行政机关违法干预契约自由、非法查封公司资产的，由涉案机关及直接责任人承担国家赔偿与个人追偿责任。

第89条【公司僵局之强制仲裁】公司内部治理陷入僵局且严重损害公共利益或中小股东权益时，法院或仲裁庭得强制裁决股份强制收购。

第90条【与其他法律衔接】本法与《反垄断法》及《数字基础设施法》发生竞合时，以维护最大私法自治与契约自由原则进行解释。

第91条【条款独立有效性】合同部分条款无效不影响其余条款及整个合同之法律效力。

第92条【施行日期】本法自公布之日起正式生效施行。
