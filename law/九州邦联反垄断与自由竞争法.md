# 第一章：总则（第1条 - 第6条）

第1条【立法宗旨】维护市场自由竞争，打破行政特许与资本垄断，保护中小企业及独立创作者之生存与创新权利。

第2条【适用范围】九州邦联主权管辖境内及数字自由港内之一切商业经营、资本并购、数字平台运营及市场竞争行为。

第3条【竞争自由原则】确认市场竞争自由为邦联经济之基本宪制，任何主体不得以行政权力或绝对资本优势破坏市场准入。

第4条【反对行政垄断】严禁各级行政机关滥用行政权力排除、限制竞争或设置地方保护壁垒。

第5条【中立监管原则】反垄断监管机构须保持完全独立，仅以维护市场效率与消费者选择为评估标准。

第6条【契约优先原则】在不违反自由竞争前提下，尊重市场主体之私法自治与契约自由。

# 第二章：市场支配地位与滥用规制（第7条 - 第15条）

第7条【市场支配地位定义】明确具有市场支配地位之认定标准（包括市场份额、控制上下游能力及进入壁垒）。

第8条【禁止不公平高价与低价倾销】禁止支配地位企业以不公平高价销售商品或以低于成本价格掠夺性定价。

第9条【禁止无正当理由拒绝交易】禁止拥有关键基础设施或核心平台之企业无正当理由拒绝与同行或下游开展业务。

第10条【禁止排他性独家交易】严禁利用市场支配地位强制或变相强制交易相对人进行独家排他交易。

第11条【禁止搭售与附加不合理交易条件】禁止在交易时强制搭售无关商品或附加苛刻、不合理的商业条件。

第12条【禁止差异化歧视待遇】禁止对条件相同的交易相对人在价格、资质或服务标准上实行不合理的差异化待遇。

第13条【平台生态封锁禁令】禁止数字平台利用操作系统或流量入口优势，对第三方应用、支付渠道或外部链接实施封锁。

第14条【算法共谋与价格协同规制】禁止企业利用大数据、人工智能或算法进行隐性价格共谋与市场划分。

第15条【支配地位自我纠错责任】具支配地位企业承担更高的互操作性与开放义务，防止生态闭环异化为市场壁垒。

# 第三章：经营者集中与并购审查（第16条 - 第24条）

第16条【集中申报标准】确立基于营业额或资产规模的经营者集中强制申报阈值，简化中小企业创新并购流程。

第17条【自由港并购特许】对数字自由港内初创企业、开源技术团队之早期并购实行“促进创新”的包容性审查。

第18条【审查核心考量因素】集中审查应重点评估对市场竞争、技术创新、中小实体生存及消费者福祉之影响。

第19条【附加限制性条件】对可能产生排除、限制竞争效果的集中，监管机构可剥离资产、剥离业务或强制开放接口。

第20条【禁止扼杀式并购】重点防范大型资本通过高价收购潜在颠覆性创新初创企业来消灭未来竞争。

第21条【未申报集中之强制纠错】对未依法申报且具有排除、限制竞争效果的集中，有权责令限期恢复到集中前状态。

第22条【审查时限与透明度】设定严格的行政审查法定时限，全程公开论证过程，防止行政拖延变相扼杀商业机遇。

第23条【跨国并购公平对待】对境内外资本实施完全平等的反垄断审查标准，严禁歧视外资或搞贸易保护。

第24条【并购申诉与听证权】涉案企业对并购审查决定不服的，享有向独立司法机关提起行政复议或诉讼之权利。

# 第四章：行政垄断与权力边界（第25条 - 第32条）

第25条【严禁滥用行政权力排除竞争】行政机关不得以发布规定、会议纪要等形式指定特定企业经营、购买特定服务。

第26条【打破地方保护与市场分割】严禁地方政府对外地商品、服务或企业进入本地市场设置歧视性收费与审批障碍。

第27条【特许经营权公开竞标】政府基础设施特许经营权必须通过公开、公平、非歧视之竞标产生，严禁暗箱操作。

第28条【政府采购公平参与】政府及其所属部门在采购时，不得对民营、外资或中小企业设置不合理的歧视性门槛。

第29条【排他性补贴审查】财政补贴不得定向用于扶持特定垄断企业以扭曲市场公平竞争，补贴细则须全面公开。

第30条【行业协会行政化遏制】严禁行业协会组织企业达成垄断协议、划分市场或变相行使行政管理职能。

第31条【公用企业强制开放】供水、供电、通信、交通等自然垄断环节之公用企业，其实际网络设施必须向社会公平开放。

第32条【违规干预之宪制追责】行政机关或官员违规插手市场竞争、实施行政垄断的，依法追究个人失职与违宪责任。

# 第五章：纵向与横向垄断协议（第33条 - 第41条）

第33条【横向价格同盟禁令】禁止具有竞争关系的经营者通过协议、决议等方式固定或者变更商品价格。

第34条【市场分割协议禁令】禁止竞争对手之间分割销售市场或者原材料采购市场。

第35条【限制产销量协议禁令】禁止联合抵制交易或限制商品的生产数量、销售数量。

第36条【联合抵制交易禁令】禁止多个企业联合对特定竞争对手或供应商实施断供、封锁等抵制行为。

第37条【纵向转售价格维持规制】除明确之品牌质量维护特例外，禁止生产商强制限定下游经销商对第三方的最低转售价格。

第38条【创新豁免条款】参与横向协议之企业若能证明该协议显著促进技术进步、产品升级且不剥夺消费者剩余，可获豁免。

第39条【宽恕制度（主动举报减免）】建立首个主动向监管机构举报垄断协议并提供关键证据者的行政处罚宽恕与豁免机制。

第40条【行业标准滥用防范】禁止通过制定技术标准恶意排挤竞争对手或变相实施横向垄断。

第41条【合法的知识产权行使豁免】正当行使专利、著作权等知识产权的行为，不视为本法所指之垄断协议，但滥用者除外。

# 第六章：数字经济与平台竞争特别规范（第42条 - 第46条）

第42条【数据要素反垄断】防止大型平台通过海量数据回音壁效应构筑不可逾越的竞争壁垒。

第43条【平台间互联互通义务】具备相当规模之即时通讯、社交及流量平台，应在技术可行前提下实现基础互联互通。

第44条【禁止自我优待（Self-Preferencing）】平台经营者不得在其自营业务中违规使用通过第三方商户数据获得的竞争优势。

第45条【数据便携与转移动态权】用户有权将其在平台上沉淀之数据完整、无损、低成本地转移至其他竞争平台。

第46条【数字广告与流量反垄断】严禁数字广告巨头在广告主、流量分发与效果监测环节捆绑销售或实施市场封锁。

# 第七章：法律责任与附则（第47条 - 第51条）

第47条【违法所得没收与高额罚款】对违反本法实施垄断、滥用支配地位或恶意并购者，处以巨额罚款及没收违法所得。

第48条【民事三倍惩罚性赔偿】因垄断行为受损之企业或个人，有权向法院提起民事诉讼，要求获得最高三倍之惩罚性赔偿。

第49条【反垄断诉讼原告资格】扩大集体诉讼与公益诉讼原告资格，支持中小企业联合对抗巨头垄断诉讼。

第50条【与其他法律衔接】本法与《数字基础设施法》及《契约法》发生竞合时，以维护最大竞争自由原则解释。

第51条【施行日期】本法自公布之日起正式生效施行。
