# 国家标志
国名：（新）九州邦联<p>
英文名：the Great States of Nyetrok / Naychok或者 the Great States of Eastland<p>
简称：GSN/GSE<p>
临时代国歌：《岂曰无衣》<p>
國家格言：书增智，武健体，礼修身。<p>
國家格言：以謙卑之心建大同社會。<p>
官方语言：普通话，各地可以自行设立蒙语、满语、沪语、粤语、壮语、川话等。<p>
国庆（暂定）：12月10日（初稿《九州计划》封笔于2025年12月10日）<p>

政府：议会代议制，总统（国家元首），总理（政府首脑），上议院院长，下议院院长，首席大法官。<p>
立法机关：上议院+下议院=国会<p>
货币：新银元（New Silver Yuan）<p>
首都：以洛阳为中心建立都市圈。（用洛阳是为了克中共，中共称毛润之为红太阳而毛一生没去洛阳。）<p>
陪都：重庆市<p>
时区：东七区（洛阳时间）为核心，跨东九区到东五区，各时区双时间同步，按当地时区作息生活。<p>
行驶方位：右，港澳左行。<p>
国兽：江豚<p>
国玉：黄龙玉<p>
国花：月季花/桂花<p>
政党：多党轮替<p>
国树：银杏<p>
国鸟：黑颈鹤<p>
