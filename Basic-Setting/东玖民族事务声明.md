# 《东玖民族事务声明》

（民间策划草案）

民族并非国家赐予，文化亦非政权塑造。

东玖认为，民族是历史、语言、血缘、生活方式与个人认同共同形成之文化共同体，而非国家进行资源配置、政治分层或行政管理之工具。

东玖建立之目的，并非消灭任何民族，而是使国家回归国家，民族回归民族。

自东玖成立之日起，国家原则上不设民族登记制度。除学术研究、文化保存、人口统计及公民自愿申报外，任何行政机关不得强制要求公民申报民族成分，亦不得以民族作为行政管理、政治权利、司法裁判、教育机会、就业资格、税收待遇及社会福利之依据。

东玖尊重一切民族、语言、宗教及文化传统之存在。

各民族皆有保存语言、文字、服饰、节庆、信仰、艺术及历史记忆之自由。地方自治州得依自治法设立符合本地历史与习俗之行政制度，如旗、盟等传统建制，国家依法予以保障。

东玖反对任何形式之民族歧视、民族压迫、民族特权及民族原罪论。

任何个人不得因其民族、血统、肤色、籍贯、宗教或文化背景而受到国家之优待或限制；任何民族亦不得因历史恩怨而承担集体罪责。

东玖承认混合血统人口之自然存在。

混合血统并非例外，而是文明交流之结果。国家不对混血人口作官方民族定义，其文化认同由本人自由决定，不受行政机关干预。

东玖认为，公民身份高于民族身份。

国家忠诚建立于共同宪法、共同法律与共同责任，而非血统与族源。凡依法取得东玖国籍者，皆为东玖公民，享有宪法所保障之一切权利，并承担相应义务。

东玖相信，多元文化并不会削弱国家，真正削弱国家者，是以民族划线制造对立，以身份政治取代法治原则。

国家之统一，建立于契约；文化之繁荣，建立于自由；民族之延续，建立于人民自身，而非国家机器。

谨以此声明，昭示东玖对于民族事务之一贯立场。

**东玖民间策划 毋明释 于安源2026年7月20日谨识**

（草案）
